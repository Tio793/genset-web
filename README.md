# Supermarket Genset — versi pertama

Buka `dist/index.html` melalui browser atau gunakan server lokal yang sedang berjalan di http://127.0.0.1:8765.

## Isi

- Homepage responsif dengan identitas merah, navy, dan putih.
- Cummins KTAA19-G6: 575 kVA prime, 650 kVA standby; tab performa, dimensi, dan kelengkapan.
- Layanan sewa, layanan teknis, pengalaman perusahaan, FAQ, dan kontak.
- Form konsultasi pembelian/sewa/layanan yang menyusun email ke sales@supermarketgenset.com. Tidak mengirim otomatis dan tidak menyimpan data pengunjung.
- Form sewa: nama, WhatsApp, kota/kabupaten, kebutuhan daya (boleh belum tahu), tanggal mulai, serta durasi. Perusahaan dan catatan opsional.
- Logo dan gambar dari materi pengguna. Nama klien ditampilkan sebagai teks.

## Batas versi ini

Ini frontend statis yang siap ditinjau. Belum ada CMS/admin, penyimpanan lead, pengiriman email dari server, integrasi WhatsApp dengan nomor tujuan terverifikasi, maupun migrasi URL situs lama. Aset canopy dan unit adalah ilustrasi brosur, bukan klaim foto konfigurasi akhir 575 kVA. Klaim sertifikasi tidak ditampilkan sebagai sertifikat terverifikasi.

## Verifikasi

Sintaks JavaScript, keberadaan aset, anchor, duplikasi ID, dan respons HTTP lokal diperiksa. Pemeriksaan visual browser belum dilakukan karena kontrol browser dinonaktifkan di Work.
